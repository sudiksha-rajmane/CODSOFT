# 🎯 Number Game

## 📌 Project Description

Number Game is a simple Java-based guessing game developed as part of the **CODSOFT Java Development Internship**.

The program generates a random number between **1 and 100** and asks the user to guess it. After each guess, the program provides feedback indicating whether the guess is **too high** or **too low**. The player has a limited number of attempts to guess the correct number.

The game also supports multiple rounds and maintains a score.

## 🚀 Features

* Generates a random number between 1 and 100
* Takes guesses from the user
* Provides "Too High" or "Too Low" hints
* Limits the number of attempts
* Supports multiple rounds
* Calculates and displays the player's score
* Validates the user's input

## 🛠️ Technologies Used

* **Java**
* **Scanner** for user input
* **Random** class for generating numbers

## ▶️ How to Run

1. Make sure Java is installed on your computer.
2. Clone or download this repository.
3. Open the `Task1_NumberGame` folder.
4. Compile the program:

```bash
javac NumberGame.java
```

5. Run the program:

```bash
java NumberGame
```

## 🎮 How to Play

1. The computer generates a random number between 1 and 100.
2. Enter your guess.
3. The program tells you if your guess is too high or too low.
4. Continue guessing until you find the correct number or run out of attempts.
5. Choose whether you want to play another round.
