# 💻 CODSOFT Java Development Internship

## 📌 About This Repository

This repository contains the projects and tasks completed as part of my **Java Development Internship at CODSOFT**.

The projects are developed using Java and focus on strengthening programming fundamentals, problem-solving skills, object-oriented programming concepts, and practical application development.

## 📂 Projects

### 🎯 Task 1 – Number Game

A Java-based number guessing game where the user attempts to guess a randomly generated number between 1 and 100.

**Features:**

* Random number generation
* User input and guess validation
* Too high / too low hints
* Limited attempts
* Multiple rounds
* Score calculation

📁 Folder: `Task1_NumberGame`

---

### 📊 Task 2 – Student Grade Calculator

A Java application that calculates a student's total marks, average percentage, and grade based on marks obtained in different subjects.

**Features:**

* Multiple subject marks input
* Marks validation
* Total marks calculation
* Average percentage calculation
* Grade assignment
* Result display

📁 Folder: `Task2_StudentGradeCalculator`

---

### 🏦 Task 3 – ATM Interface

A Java-based console application that simulates basic ATM operations using separate `ATM` and `BankAccount` classes.

**Features:**

* Check account balance
* Deposit money
* Withdraw money
* Insufficient balance validation
* Input validation
* Transaction messages

📁 Folder: `Task3_ATMInterface`
