# 📊 Student Grade Calculator

## 📌 Project Description

The **Student Grade Calculator** is a Java-based application developed as part of the **CODSOFT Java Development Internship**.

The application takes the marks obtained by a student in each subject, calculates the **total marks** and **average percentage**, and assigns a corresponding **grade** based on the percentage achieved.

## ✨ Features

* Accepts marks for multiple subjects.
* Validates marks to ensure they are between **0 and 100**.
* Calculates the **total marks** obtained.
* Calculates the **average percentage**.
* Assigns a grade based on the average percentage.
* Displays the final result in a clear format.

## 🛠️ Technologies Used

* **Java**
* **Scanner Class** – for taking user input.
* **Conditional Statements** – for grade calculation.
* **Loops** – for processing marks for multiple subjects.

## 📋 Grade Criteria

| Average Percentage | Grade |
| ------------------ | ----- |
| 90% – 100%         | A     |
| 80% – 89%          | B     |
| 70% – 79%          | C     |
| 60% – 69%          | D     |
| 50% – 59%          | E     |
| Below 50%          | F     |

## ▶️ How to Run

### 1. Compile the program

```bash
javac StudentGradeCalculator.java
```

### 2. Run the program

```bash
java StudentGradeCalculator
```

### 3. Enter the required information

Enter the number of subjects followed by the marks obtained in each subject.
